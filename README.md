# Agregador de Dados para Imposto de Renda (Excel)

## Sobre o projeto
Ferramenta em Excel que organiza as informações essenciais para a declaração de Imposto de Renda, com menus de navegação, validações automáticas e links rápidos.

## Funcionalidades
- Menu de navegação entre as abas
- Validação de dados nas entradas
- Links rápidos para acesso às informações
- Interface simples e prática

## Como usar
1. Baixe o arquivo `nome-da-planilha.xlsx`.
2. Abra no Excel e habilite a edição.
3. Navegue pelo menu e preencha as abas.
